# #20 App icon sets — assembly instructions (NOT dylib resources)

The 6 alternate-icon PNGs here are bundled into the **app**, not the dylib.
Source: the TikTok You 5.0 (47.4.3) APK's `ttmod_launcher_*` resources —
raster foreground/background PNGs for HLX / MD / Metal, vector drawables
rendered to PNG for Cheese / Nostalgic / Parody. No icons were downloaded
from the web. The 7th style is the stock Default icon (no file needed).

Files (all 1024×1024 PNG):
- `AppIcon-Cheese.png`, `AppIcon-Hlx.png`, `AppIcon-Md.png`,
  `AppIcon-Metal.png`, `AppIcon-Nostalgic.png`, `AppIcon-Parody.png`

## Assembler steps (coordinator, at IPA assembly time)

1. Copy the 6 PNGs into `Payload/TikTok.app/` (next to the stock `AppIcon` files).
2. Add this to the app's `Info.plist` (inside the existing top-level dict):

```xml
<key>CFBundleIcons</key>
<dict>
    <key>CFBundleAlternateIcons</key>
    <dict>
        <key>Cheese</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Cheese</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
        <key>HLX</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Hlx</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
        <key>MD</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Md</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
        <key>Metal</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Metal</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
        <key>Nostalgic</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Nostalgic</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
        <key>Parody</key>
        <dict>
            <key>CFBundleIconFiles</key>
            <array><string>AppIcon-Parody</string></array>
            <key>UIPrerenderedIcon</key><false/>
        </dict>
    </dict>
</dict>
```

3. The dylib calls `setAlternateIconName:` with the key (`Cheese`, `HLX`, …)
   or `nil` for Default. If a set is missing, the call fails soft (log + toast,
   current icon kept) — see `TikTokModV1 +applyAlternateIconNamed:`.

Rebuild note: the PNGs were generated by `/tmp/make_icons.py` (androguard AXML
parse + cairosvg render + PIL composite). Re-run it if the APK changes.
